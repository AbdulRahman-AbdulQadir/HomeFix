
# CleanPro – Architecture and Design Decisions

## UI/UX Design

### Brand Direction
Balanced Green – professional, fresh and trustworthy.

### Color Palette
- Forest Green: #14532D
- Primary Green: #15803D
- Light Green: #86EFAC
- Background: #F8FAF9
- Main Text: #17211B
- Secondary Text: #647067
- Borders: #E5EAE6

### Typography
Inter or a similar modern sans-serif font.

### Frontend Technologies
- Django Templates (DTL)
- Tailwind CSS
- JavaScript
- Alpine.js when necessary

### Design Principles
- Mobile-first responsive design.
- Consistent spacing and typography.
- Reusable components.
- Accessible colors and controls.
- Clear booking calls to action.
- Simple customer navigation.
- Professional photography.
- Avoid unnecessary animations.

### Homepage Sections
1. Navigation
2. Hero
3. Services Overview
4. Why Choose CleanPro
5. How It Works
6. Service Areas
7. Testimonials (only clearly identified demo content)
8. Booking CTA
9. Footer

### Important Business Rule
A booking request is not an automatically confirmed appointment.
